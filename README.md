# Flowday — Daily Routine OS

![Flowday Banner](https://img.shields.io/badge/version-1.0.0-blue.svg)

> A sophisticated daily routine planner that transforms time management into an intuitive, visual experience.

## 🌟 Features

### 📊 Visual Timeline
- **24-hour interactive timeline** with drag-and-drop activity blocks
- **Resizable segments** with 15-minute snap precision
- **Real-time clock needle** showing current time position
- **Color-coded activities** for instant recognition

### 🎯 Intelligent Planning
- **Reality Mode** - Real-time tracking of your current scheduled activity
- **Smart suggestions** based on your daily patterns
- **Goal tracking** with productivity scoring system
- **Category-based time distribution** analysis

### 📅 Flexible Scheduling
- **7-day view** with quick navigation between days
- **Copy from yesterday** functionality
- **Template system** - Save and reuse successful routines
- **Activity duration tracking** in hours and minutes

### 📈 Analytics & Insights
- **Weekly overview** with total planned hours
- **Category breakdown** charts
- **Productivity score** based on goal completion
- **Time distribution** pie charts

### 🎨 Customization
- **Dark/Light theme** support
- **Custom color picker** for activities
- **Flexible category system** with custom categories
- **Editable goals** for sleep, work, and fitness

### 💾 Data Management
- **Local storage persistence**
- **JSON import/export** functionality
- **Browser notification** reminders
- **Clear all data** option
